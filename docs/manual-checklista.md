# Manualen – checklista

Gå igenom i denna ordning. Kryssa när det stämmer.  
Nästa utvecklingspass: **skrivytan (TipTap)** – den är den svagaste delen just nu.

## Fönster

- [ ] Ingen modul-sidebar inne i Manualen (pärm, inte dashboard)
- [ ] Titelrad visar dokumentnamn
- [ ] Stäng (X) tar tillbaka
- [ ] Minimera (streck) döljer trädet
- [ ] Fönsterläge (ruta) visar trädet igen
- [ ] Helskärm / lämna helskärm (fyrkant med pilar) – inte samma som fönsterläge
- [ ] Tre flikar: Grundinställningar | Arbetsmanual | Original
- [ ] Aktiv flik när man kommer in: Arbetsmanual
- [ ] Vänster träd 288 px, mitten vitt papper
- [ ] Mobil: trädet som utfällbar meny

## Tom pärm (första dagen)

- [ ] Ingen seed, inga Policyer/Mål/Processer, ingen ISO-katalog
- [ ] Sök: “Hitta avsnitt…”
- [ ] Knapp: “Skapa 1.0”
- [ ] Text: “Manualen är tom. Skapa första kapitlet. Numret låses vid skapande.”

## Träd och nummer

- [ ] Skapa 1.0 ger `1.0 Ledningssystemet`
- [ ] Nästa rotkapitel blir 2.0
- [ ] Nytt underavsnitt under 1.0 blir 1.1, barn till 1.1 blir 1.1.1
- [ ] Högerklick/meny: Nytt underavsnitt, Byt namn, Dölj
- [ ] Byt namn ändrar inte numret
- [ ] Senast öppnad rad syns markerad
- [ ] Sök hittar avsnitt på namn

## Papper och utseende (Laser Tech)

- [ ] Vitt A4 (`document-paper`), även i mörkt läge
- [ ] Sidhuvud: streckad ram “Logotyp” + företagsnamn (inte lila märke)
- [ ] Primär knapp petrol `#005F73`, vit text
- [ ] Ingen neon som knapp i ljust läge
- [ ] Rundning 6 px, Geist/Inter
- [ ] Svenska vanliga ord: Spara, Publicera, Skapa 1.0, Visa original

## Skriva (Arbetsmanual)

- [ ] Status: “Arbetsmanual – du kan ändra”
- [ ] Verktygsrad: ångra, gör om, fet, kursiv, understruken, lista, numrerad lista, tabell, bild, länk, spara, skriv ut
- [ ] Spara behåller texten efter omladdning
- [ ] Osparat varnar om man byter dokument
- [ ] Tabell går att infoga och skriva i
- [ ] Lista och fetstil syns på papperet
- [ ] Bild hamnar i dokumentet (inte bara som bilaga)
- [ ] Skrivytan tar emot klick, markör och tangentbord utan att hoppa

**Känt:** skrivytan är inte bra nog ännu. Detta är nästa jobb.

## Original

- [ ] Före publicering: “Inget publicerat dokument ännu”
- [ ] Publicera låser en utgåva
- [ ] Status: “Original – gällande version, låst”
- [ ] Går inte att ändra originaltexten
- [ ] Utgåva 1, 2, 3 syns i historiken
- [ ] Skriv ut öppnar utskrift

## Grundinställningar

- [ ] Namn, utfärdare, granskare, godkännare
- [ ] Företagsnamn syns på papperet efter sparning
- [ ] Logotyp-ram finns (bilduppladdning får komma sen)

## Bilagor

- [ ] Ladda upp fil
- [ ] Filen syns i listan
- [ ] Ladda ner / ta bort

## Behörighet

- [ ] Admin kan skapa, spara, publicera
- [ ] Tittare kan läsa original, inte ändra arbetsmanualen

## Klart när

En admin ser tom pärm, skapar 1.0, skriver på vitt papper, sparar, publicerar och ser låst original. Laser Tech, inte lila/blått. Skrivytan ska kännas som ett vanligt dokument – det är nästa steg.
