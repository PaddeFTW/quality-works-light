# SQL-ordning

Kör i Supabase SQL Editor, en fil i taget:

1. `schema.sql`
2. `fix_organizations_permission.sql` om den behövs
3. `schema_phase_a.sql`
4. `schema_phase_a_profiles.sql` om den behövs
5. `schema_phase_b.sql`
6. `schema_phase_c.sql` — avvikelser, förslag, årshjul

Utan `schema_phase_c.sql` visar Avvikelse, Förslag och Årshjul en svensk felrad i stället för att låtsas att data finns.
