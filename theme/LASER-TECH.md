# Laser Tech i Quality Works Light

Tema v2.0 är mappat till shadcn-tokens i `app/globals.css`.

- Light default: canvas `#EAF6F9`, primärknapp `#005F73` + vit text
- Dark / Hög kontrast: canvas `#000`, primärknapp `#00E5FF` + text `#001116`
- Toggle: System | Ljust | Hög kontrast (`next-themes`, localStorage)
- Radius 6px. Font Geist Sans, fallback Inter.
- Ingen hex i komponenter — bara `bg-primary`, `bg-background`, `border-border`.
